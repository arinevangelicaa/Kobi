# Kobi 
Kobi adalah aplikasi berbasis AI yang membantu mahasiswa mencatat pola makan dalam bahasa sehari-hari, menganalisis kesenjangan gizi harian (bukan sekadar hitung kalori), 
dan menemukan menu bergizi dengan anggaran terbatas dari warung, kaki lima, dan pasar terdekat, disesuaikan dengan sela jadwal kuliah pengguna.
